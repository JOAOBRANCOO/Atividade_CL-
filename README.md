# Atividade_CL-

API REST com Spring Boot para gerenciamento de clãs.

## Endpoints de Clã

- `POST /cla` - Cadastrar novo clã
- `GET /cla` - Listar todos os clãs
- `GET /cla/id/{id}` - Buscar clã por ID
- `GET /cla/nome/{nome}` - Buscar clã por nome
- `GET /cla/descricao/{descricao}` - Buscar clãs por parte da descrição
- `PUT /cla/{id}` - Atualizar clã por ID
- `DELETE /cla/{id}` - Deletar clã por ID
